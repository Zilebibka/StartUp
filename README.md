# 🚀 Dead Code Marketplace (AI-аудит кода)

## 🎯 Ценностное предложение

Для малых веб-студий и предпринимателей, которым нужно быстро запустить MVP,  
наша платформа позволяет купить проверенную кодовую базу и сократить срок разработки с 4 месяцев до 2 недель,  
улучшая Time-to-Market на ~70% по сравнению с разработкой с нуля,  
при условии использования AI-аудита и стандартизированных метрик качества.

### Почему это работает:
- AI-аудит снижает стоимость проверки кода в 100+ раз
- Готовые проекты заменяют написание с нуля
- Рынок уже перегружен «мертвым кодом»

---

## 🧑‍💻 User Flow (основной сценарий)

1. Пользователь осознает потребность (нужно быстро MVP)
2. Заходит на платформу
3. Вводит параметры поиска
4. Получает список проектов с AI-оценкой
5. Открывает карточку проекта
6. Изучает отчет (архитектура, баги, сложность)
7. Покупает проект
8. Скачивает код и запускает разработку

---

## 🔁 Альтернативный сценарий (продавец)

1. Разработчик имеет заброшенный проект
2. Загружает репозиторий
3. Проходит AI-аудит
4. Получает отчет
5. Публикует лот
6. Получает оплату после продажи

---

## ⚙️ Функции продукта

### Core (MVP)

## 📋 Backlog MVP

| ID | User Story | Acceptance Criteria | Priority |
|----|------------|--------------------|----------|
| 1 | Как покупатель, хочу искать проекты | Есть поиск и фильтры | Must |
| 2 | Хочу видеть AI-аудит | Есть отчет по коду | Must |
| 3 | Хочу купить код | Работает оплата | Must |
| 4 | Как продавец, хочу загрузить код | Репозиторий принимается | Must |
| 5 | Хочу видеть рейтинг продавца | Отображается рейтинг | Should |

## 🔒 Нефункциональные требования

- Время отклика ≤ 2 сек
- Доступность 99%
- Безопасная передача данных (HTTPS)
- Проверка кода на уязвимости
- Масштабируемость (микросервисы)
- Интеграция с GitHub/GitLab
